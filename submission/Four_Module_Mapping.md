## 2. Specialized Decision-Support Enhancement: Machine Learning

In addition to the four core TPDS-III modules, **StockPilot** incorporates an advanced machine learning microservice serving as a specialized decision-support enhancement for inventory controllers:

- **Technology Stack:** Python 3.11, FastAPI, Pandas, NumPy, Scikit-learn, and XGBoost Regressor (`XGBRegressor`).
- **Integration Boundary:** Operates as an internal microservice on the private `stockpilot-net` network (port 8000). Express invokes it via HTTP JSON with timeout circuits and automatic graceful fallback to 7-day moving-average replenishment if ML is unreachable.
- **Model Accuracy:** Trained on 19,110 daily SKU records across 35 items; achieved **WAPE of 8.76%** (outperforming the Seasonal Naive baseline by 41.09%).
- **Governance & Safeguards:** Strict zero-lookahead feature lag constraints (`shift(1)`), non-negative predicted demand clamps, and mandatory human-in-the-loop manager approval before purchase orders are submitted.
- **Academic Note:** This microservice acts as an enhancement to the core Module 3 backend; the primary application web server remains Node.js/Express with Microsoft SQL Server 2022.
